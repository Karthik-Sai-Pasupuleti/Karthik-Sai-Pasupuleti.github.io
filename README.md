# Karthik Sai Pasupuleti — Personal Research Website

A multipage personal site for my PhD on **vision-language-action (VLA) models with spiking neural networks** at AImotion Bavaria (THI Ingolstadt). Built as static HTML/CSS/JS — no build step.

## Pages
- `index.html` — Home
- `research.html` — Research & PhD vision (interactive spiking-neuron animation)
- `publications.html` — Open-source projects & papers
- `literature.html` — PRISMA literature review
- `about.html` — Bio, experience, skills, contact

## Assets
- `assets/css/site.css` — shared styles
- `assets/js/site.js` — shared behaviour + animations
- `assets/video/` — background video loops
- `assets/img/` — video poster frames

## Deploy (GitHub Pages)
This is a plain static site, so GitHub Pages serves it directly from the repo root.
All paths are relative, so it works both as a user site (`<username>.github.io`)
and as a project site (`<username>.github.io/<repo>/`). The `.nojekyll` file tells
Pages to serve files as-is (no Jekyll processing).

See the deployment steps shared in chat.
